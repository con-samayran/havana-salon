# Havana The Salon

Premium React + Vite salon website for Havana The Salon, Jubilee Hills, Hyderabad.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes
- Supplied Havana salon photography is included in `src/assets/` +.
- Booking form opens WhatsApp with a pre-filled appointment message.
- Call, Instagram and Google Maps CTAs are wired.
- No live Instagram API or fake review ratings are used.
